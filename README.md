# KARAT website — GitHub Pages

Статичка веб-страна за [karaprint.shop](https://karaprint.shop/). Содржината се објавува од коренот на GitHub репозиториумот преку **Settings → Pages → Deploy from a branch → main / (root)**.

`CNAME` е поставен на `karaprint.shop`. Македонската верзија е во `index.html`, а англиската во `en/index.html`. Двете користат исти CSS, JavaScript и слики.

Формуларот отвора апликација за е-пошта со подготвено барање до `contact@karaprint.shop`. Тој самиот не испраќа податоци на сервер.

Контактите на страницата се `contact@karaprint.shop`, `+389 78 668 618` и [@karalasersko](https://www.instagram.com/karalasersko/). Посебниот блок за GWEIKE G2 Pro е на `#machine-g2pro`.
