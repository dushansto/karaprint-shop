# KARAT website — GitHub Pages

Статичка веб-страна за `karaprint.shop`. Содржината на оваа папка се објавува од коренот на GitHub репозиториумот преку **Settings → Pages → Deploy from a branch → main / (root)**.

`CNAME` е поставен на `karaprint.shop`. Потребни се соодветни DNS записи во Porkbun и вклучување на **Enforce HTTPS** во GitHub Pages откако сертификатот ќе биде достапен.

Формуларот подготвува текст за копирање; не испраќа податоци. Контакт податоци треба да се додадат кога ќе бидат достапни.

Изворите на примерните фотографии се наведени во [PHOTO_SOURCES.md](PHOTO_SOURCES.md).
